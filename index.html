Settings & help

Search options

StreamNest now searches through community-run Invidious servers. No Google API key is needed. These public servers can be slow, unavailable, or block requests from some browsers, so search is best-effort.

Search provider information: official public instance list · API documentation.

Why might a video not play?

YouTube's official embedded player streams the video. Some videos cannot be embedded because of creator settings, privacy, age, regional or other restrictions. Use the Open on YouTube link for those videos. StreamNest does not download, rehost, scrape or bypass restrictions.

StreamNest is independent and is not affiliated with YouTube or Google. YouTube's player, availability rules, branding and terms still apply.
